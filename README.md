# Interactive Wall Calendar

A premium interactive wall-calendar inspired component built with Next.js, React, Tailwind CSS, and Framer Motion.

## Features
- Wall calendar inspired layout with hero image
- Date range selection using click and drag
- Month notes and selected range notes
- LocalStorage persistence
- Holiday region switching (India / USA / Global)
- Dark mode toggle
- Keyboard accessible calendar navigation
- Responsive design for desktop and mobile

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Framer Motion
- Lucide React

## How to Run
```bash
npm install
npm run dev
